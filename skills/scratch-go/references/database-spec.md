# 数据库规范

## 1. 适用范围

本规范用于数据库表结构、迁移及数据访问代码的开发与审查。数据库相关规范统一维护在本文件中，与 [Go 工程模式](go-patterns.md)配合使用。数据库错误的语义转换与传播遵守 [错误处理](error.md)，资源生命周期遵守 Go 工程模式。

## 2. 外键

禁止使用数据库外键约束，包括在建表、迁移脚本中显式声明，以及通过 ORM 自动迁移或模型关联隐式生成。使用 ORM 时，必须关闭或避免自动创建外键约束。

表间可以通过关联字段表达业务关系，引用有效性及关联数据的更新、删除规则由应用逻辑维护，不依赖数据库外键或其级联行为。

## 3. 查询

**避免 N+1 查询：**列表关联数据使用批量查询、预加载或 JOIN，避免在循环中逐条查询数据库；查询范围限定为当前结果集，避免全量加载。
